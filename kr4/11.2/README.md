# Задание 11.2 - Асинхронные модульные тесты с Faker

## Установка

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Выполненные требования

1. ✓ Подготовлено окружение:
   - Установлены pytest, pytest-asyncio, httpx, Faker
   - Структурирован проект с папкой tests/ и pytest.ini

2. ✓ Асинхронные тесты для всех трёх эндпоинтов:
   - Создание пользователя (201)
   - Получение существующего пользователя (200)
   - Получение несуществующего пользователя (404)
   - Удаление существующего пользователя (204)
   - Повторное удаление пользователя (404)

3. ✓ HTTP-клиент без реального сервера:
   - Использован httpx.AsyncClient с ASGITransport
   - Тесты обращаются напрямую к приложению без запуска Uvicorn

4. ✓ Генерация данных через Faker:
   - Использован Faker для создания реалистичных username и age
   - Проверены как валидные, так и граничные значения (18, 150)

5. ✓ Изоляция состояния:
   - Обеспечено чистое состояние между тестами
   - In-memory словарь очищается до/после каждого теста через fixture

6. ✓ Запуск и проверка:
   - Все 12 тестов проходят успешно

## Запуск

Локальный запуск приложения:
```bash
uvicorn app.main:app --reload
```

Запуск асинхронных тестов:
```bash
pytest tests/test_main.py -v
```

## Тестовые сценарии

1. `test_create_user_201` - создание пользователя с проверкой статуса 201
2. `test_create_user_response_structure` - проверка структуры ответа
3. `test_get_existing_user_200` - получение существующего пользователя
4. `test_get_nonexistent_user_404` - попытка получить несуществующего пользователя
5. `test_delete_existing_user_204` - удаление существующего пользователя
6. `test_delete_nonexistent_user_404` - попытка удалить несуществующего пользователя
7. `test_delete_same_user_twice_404` - повторное удаление пользователя
8. `test_create_multiple_users` - создание нескольких пользователей с проверкой уникальности ID
9. `test_isolation_between_tests` - проверка изоляции состояния между тестами
10. `test_get_user_after_create_with_faker_data` - создание и получение с Faker данными
11. `test_edge_case_age_boundary` - граничное значение возраста (18)
12. `test_edge_case_large_age` - граничное значение возраста (150)

## Особенности

- Асинхронные тесты через `@pytest.mark.asyncio`
- Использован `httpx.AsyncClient` с `ASGITransport` для прямого обращения
- `Faker` для генерации реалистичных данных
- `pytest-asyncio` для управления асинхронными тестами
- Fixture для изоляции состояния между тестами

## Структура

- `app/main.py` - основное приложение FastAPI с тремя эндпоинтами
- `tests/test_main.py` - 12 асинхронных тестов
- `pytest.ini` - конфигурация pytest для асинхронных тестов
