# Задание 11.1 - Модульные тесты для FastAPI

## Установка

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Выполненные требования

1. ✓ Настроено приложение FastAPI с тремя эндпоинтами API:
   - `POST /users` - создание пользователя (201)
   - `GET /users/{user_id}` - получение пользователя (200 или 404)
   - `DELETE /users/{user_id}` - удаление пользователя (204 или 404)

2. ✓ Написаны модульные тесты для каждого эндпоинта
   - Использован TestClient для отправки HTTP-запросов
   - Протестированы различные сценарии и крайние случаи

3. ✓ Тестовые примеры организованы в отдельные функции
   - Каждый тест использует assert для проверки результатов

4. ✓ Все 7 тестов проходят успешно

## Запуск

Локальный запуск приложения:
```bash
uvicorn app.main:app --reload
```

Запуск тестов:
```bash
pytest tests/test_main.py -v
```

## Тестовые сценарии

1. `test_create_user_valid` - создание пользователя возвращает 201
2. `test_create_user_multiple` - создание нескольких пользователей с уникальными ID
3. `test_get_user_existing` - получение существующего пользователя возвращает 200
4. `test_get_user_not_found` - получение несуществующего пользователя возвращает 404
5. `test_delete_user_existing` - удаление существующего пользователя возвращает 204
6. `test_delete_user_not_found` - удаление несуществующего пользователя возвращает 404
7. `test_delete_user_twice` - повторное удаление пользователя возвращает 404

## Структура

- `app/main.py` - основное приложение FastAPI
- `tests/test_main.py` - 7 модульных тестов
- В тестах используется TestClient для синхронного тестирования
- База данных в памяти (словарь) очищается перед/после каждого теста
